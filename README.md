# Doom Retro RL

This repository contains the Doom Retro reinforcement learning environment, controllers, training scripts, and related RL code only.

Excluded from this repository:
- Python virtual environment (`src/Rl/venv/`)
- built extensions and compiled objects
- model checkpoints and saved weights
- data clips and dataset files
- trajectories and temporary artifacts

## Included folders
- `src/Rl/action`
- `src/Rl/controller`
- `src/Rl/detectors`
- `src/Rl/env`
- `src/Rl/Helper`
- `src/Rl/loggers`
- `src/Rl/models`
- `src/Rl/navigation`
- `src/Rl/observation`
- `src/Rl/recording`
- `src/Rl/rewards`
- `src/Rl/scripts`
- `src/Rl/training`
- `src/Rl/utils`

## Notes
This is a code-only WIP release intended for publishing the RL components without the large build artifacts and datasets.
